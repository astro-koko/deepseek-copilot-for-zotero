# Deepseek Copliot

[![Release](https://img.shields.io/github/v/release/astro-koko/deepseek-copilot-for-zotero?display_name=tag&style=flat-square)](https://github.com/astro-koko/deepseek-copilot-for-zotero/releases)
[![Zotero](https://img.shields.io/badge/Zotero-7--10-CC2936?style=flat-square)](https://www.zotero.org/)

`Deepseek Copliot` 是一个给 Zotero 用的 AI 论文阅读插件。

你在 Zotero 里选中一篇论文，或者在阅读器里打开 PDF 后，插件会自动关联当前论文内容，让你直接提问、总结、解释和追问，不需要再把论文复制到别的聊天工具里。

它也不再把不同文献的对话混在一起。每篇论文或 PDF 都可以保留自己的会话上下文，你在多篇文献之间来回切换时，切回原文献还能继续之前的阅读线程。

产品方向可以用一句话收敛：**一个对话只围绕一篇论文，让论文尽可能完整地留在上下文里，只在对话真正接近模型窗口上限时压缩较早的交流。**

## 1.0 体验更新

- **流式回复更顺滑**：长回答生成时减少界面卡顿，阅读位置不会因为持续刷新而频繁跳动。
- **侧栏会跟随 Zotero 宽度重排**：聊天内容和输入框会适应宽、窄两种阅读窗格；长文本正常换行，代码、表格和超长公式只在自身区域滚动，不再把整块对话挤出侧栏。
- **比较信息更好读**：回答提示词会优先使用纵向分组列表或三列以内的小表，减少在窄侧栏里横向拖动宽表的情况。
- **长论文对话更连贯**：只要完整论文能放进模型窗口，就优先保留全文；长时间追问接近上限时，插件只整理较早交流，并保留论文和最近讨论。

## 安装

推荐优先通过 Zotero 插件市场安装。Zotero 7、8、9、10 用户可以搜索 `Deepseek Copliot`，等待插件市场数据源刷新后直接下载安装。

如果某个 Zotero 版本筛选页暂时还搜不到，请先从本仓库的 GitHub Releases 手动安装最新 `.xpi`。插件市场通常需要等待公开 feed 刷新；维护者可以用 `npm run marketplace:check -- --target <7|8|9|10>` 检查数据源是否已经收录对应版本。

## 它能做什么

- 围绕当前论文直接提问、总结、解释和追问
- 打开 PDF 后自动加载当前 PDF 的阅读上下文
- 同一篇 PDF 在本地缓存有效期间只解析一次，不会在每次提问时反复提取；聊天接口仍会随每轮请求携带正文，但保持稳定的论文前缀以利用服务端上下文缓存
- 在多篇论文或多个 PDF 标签之间切换时，按当前文献保持各自会话
- 不再提供人为的 `maxContextBudget` 限制：只要完整论文能放进模型上下文，就优先保留全文
- 当论文与对话预计达到模型上下文窗口约 90% 时，在当前会话内自动压缩较早的对话并提醒读者；论文全文和最近对话优先保留，不会自动新建或切换会话
- 如果一篇异常长的论文单独就超过模型上下文窗口，插件会直接报错，不会静默截断或自动拆分正文
- 通过 `/` 快捷命令快速触发总结、解释、方法拆解、研究局限等常用操作
- 在设置页编辑默认命令，或新增自己的自定义命令
- 在聊天回答中渲染 LaTeX 公式，支持行内公式和独立公式块
- 更适合快速读懂论文主旨、方法、结论和细节
- 需要时可以开启联网查证

## 怎么用

1. 在 Zotero 文库中选中一篇论文，或者直接打开一篇 PDF。
2. 打开右侧 `Deepseek Copliot` 面板。
3. 直接输入问题，或者先输入 `/` 调出快捷命令。
4. 如果你切到另一篇论文或另一个 PDF，插件会优先恢复当前文献对应的会话，而不是把不同文献的聊天记录串在一起。

## 上下文与资源占用

- 一个对话绑定一篇论文或当前 PDF，不把多篇全文混入同一个窗口。
- 插件会在内存中缓存最近使用的少量 PDF 文本，避免每轮重新运行全文提取；遇到较长 PDF 时最多保留当前这一份，避免同时占用过多内存。
- 当前聊天接口仍需在每轮请求中携带论文上下文；插件保持论文部分为稳定前缀，避免在同一请求里重复拼接正文，并尽量利用 DeepSeek 的上下文缓存降低重复计算成本。
- 90% 是当前会话内自动整理对话的软阈值，不是论文长度上限。达到该阈值时，插件先摘要较早对话并留出后续追问空间，减少连续提问时反复压缩；压缩不会新建或切换会话。
- 完整论文本身若超过模型硬上限，插件会直接停止发送并报错，不做自动拆分。此类情况预计只会出现在少数异常长文档中。

你可以这样问：

- “帮我总结这篇论文”
- “/总结 这篇论文的核心贡献”
- “/方法 解释一下作者的方法设计”
- “这篇论文的方法核心是什么？”
- “这篇论文的结论和局限有哪些？”

## 当前版本

当前稳定版本是 `v1.0.0`。这一版继续使用 Zotero 7、8、9、10 共用的统一发布包，用同一个 XPI 和同一个版本号发布：

- Zotero 7、8、9、10 都使用 `Deepseek.Copliot-1.0.0.xpi`，不拆分不同版本号
- 流式回答更顺滑，Library 和 Reader 侧栏会在宽、窄窗格中自动重排
- 比较类回答优先使用纵向分组或三列以内的小表，减少侧栏横向滚动
- 普通括号英文不再被误识别为公式，超长公式仍可在公式区域内横向查看
- 保持开发测试包和正式发布包同源：测试通过后，正式包只更换版本元数据，不再改动功能代码

## 第一次使用

1. 打开 `Settings -> Deepseek Copliot`。
2. 填写你的 `DeepSeek API Key`。
3. 点击“验证连接”确认可以正常使用。
4. 如果你需要联网查证，可以保留默认查证来源，或者切换到 `Tavily`。

相关入口：

- DeepSeek Platform: [platform.deepseek.com](https://platform.deepseek.com/)
- Tavily App: [app.tavily.com](https://app.tavily.com/)

## 手动安装

如果你不想走插件市场，也可以从 GitHub Releases 手动安装：

1. 打开本仓库的 GitHub Releases 页面。
2. 下载最新的 `Deepseek.Copliot-<version>.xpi`。
3. 在 Zotero 中打开 `工具 -> 插件`。
4. 点击右上角齿轮菜单，选择 `Install Add-on From File...`。
5. 选中下载好的 `.xpi` 文件并完成安装。
6. 重启 Zotero。

当前稳定版本是 `v1.0.0`，手动安装文件名为 `Deepseek.Copliot-1.0.0.xpi`。
