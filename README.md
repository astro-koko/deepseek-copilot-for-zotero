# Deepseek Copliot

[![Release](https://img.shields.io/github/v/release/astro-koko/deepseek-copilot-for-zotero?display_name=tag&style=flat-square)](https://github.com/astro-koko/deepseek-copilot-for-zotero/releases)
[![Zotero](https://img.shields.io/badge/Zotero-7--10-CC2936?style=flat-square)](https://www.zotero.org/)

> **🎉 v1.1.0 重要更新**：原生集成 DeepSeek Search 联网搜索！无需配置 MCP 服务器，勾选即用，让 AI 在阅读论文时自动查证最新信息。

读论文时，真正打断思路的往往不是提问，而是反复搬运上下文：从 Zotero 复制片段、切到聊天工具、重新说明正在读哪篇论文；看完几篇文献再回来，之前的讨论也已经散在不同对话里。

`Deepseek Copliot` 把 AI 放进 Zotero 的阅读现场。选中文献或打开 PDF，就能在右侧边栏直接提问、总结、解释和追问，让问题始终贴着正在读的论文发生。

**它不是一个通用聊天窗口，而是一位以论文为单位组织记忆的阅读助手。** 每篇论文或 PDF 都有自己的会话；在多篇文献之间切换后，回到原文献即可接续原来的讨论，不会把不同论文的上下文混在一起。

## 为什么选择 Deepseek Copliot

- **不打断阅读流**：不必在 Zotero 与外部聊天工具之间来回复制、切换和补充背景。论文、提问与回答在同一个工作区完成。
- **每篇论文都有连续记忆**：会话与当前文献绑定。你可以今天问方法，明天回来继续追问结论、局限或实验细节，而不是从头交代上下文。
- **回答尽量基于完整论文，而非零散片段**：只要论文能放进模型上下文，就优先保留全文；接近窗口上限时，先整理较早交流，为后续追问留出空间。
- **专为 Zotero 侧栏而做**：流式回答不会频繁拉扯阅读位置，窄侧栏中长文本会重排，代码、表格和超长公式只在自身区域滚动。
- **🆕 原生联网搜索，无需折腾 MCP**：直接集成 DeepSeek Search API，设置中一键启用即可让 AI 自动查证最新信息。不用再配置复杂的 MCP 服务器、不用安装额外工具，开箱即用。

**核心原则：一个对话围绕一篇论文，让 AI 真正参与阅读，而不是成为另一处需要管理的对话。**

## 🚀 1.1.0 重大更新

### 🔍 DeepSeek Search 原生集成

**终于不用再折腾 MCP 联网搜索配置了！** v1.1.0 原生集成 DeepSeek 官方的 Search API，让 AI 在阅读论文时自动查证最新信息：

- ✅ **一键启用**：设置中勾选"启用联网搜索"即可，无需安装 MCP 服务器、无需额外配置
- ✅ **智能查证**：AI 会根据你的问题自动搜索相关的最新研究、背景知识、技术文档
- ✅ **来源透明**：搜索结果会明确标注来源链接，与论文内容清晰区分，便于交叉验证
- ✅ **论文优先**：联网搜索仅作补充，AI 的主要回答仍然基于当前论文全文

**使用场景示例**：
- 问"这篇论文提到的 Transformer 架构有什么最新改进？" → AI 会结合论文内容 + 最新研究进展回答
- 问"作者使用的数据集在最近有更新版本吗？" → AI 会自动查证数据集的官方信息
- 问"这个方法在工业界有哪些实际应用？" → AI 会补充论文之外的应用案例

### 其他改进

- **更精准的推理控制**：支持调整模型推理深度（`reasoning_effort: low/max`），在回答速度与深度思考质量之间灵活平衡
- **UI 细节优化**：修复侧栏在窄宽度下的内容裁剪问题，改善长公式和代码块的显示体验

### 1.0 核心能力回顾

- **流式回复更顺滑**：长回答生成时减少界面卡顿，阅读位置不会因持续刷新频繁跳动。
- **侧栏自适应**：聊天内容和输入框会随 Zotero 侧栏宽度重排；长文本正常换行，代码、表格和超长公式只在自身区域滚动，不再挤出对话。
- **比较信息更易读**：回答优先使用纵向分组列表或三列以内的小表，减少窄侧栏里的横向滚动。
- **长论文对话更连贯**：完整论文能放进模型窗口时会优先保留全文；接近上限时只整理较早交流，并保留论文和最近讨论。

## 核心能力

- 围绕当前论文直接提问、总结、解释和追问
- 打开 PDF 后自动关联当前阅读上下文，并按文献保存各自会话
- 通过 `/` 快捷命令快速执行总结、解释、方法拆解和研究局限等操作
- 在设置中调整默认命令，或创建自己的常用命令
- 支持 Markdown 和 LaTeX：行内公式、独立公式、列表、代码与表格均会在侧栏中妥善呈现
- **🆕 原生 DeepSeek 联网搜索**：无需配置 MCP，设置中一键启用，AI 自动查证最新信息，补充当前论文之外的公开知识
- 适合快速把握论文的研究问题、方法、结论、局限和关键细节

## 开始使用

1. 安装插件后，打开 `Settings -> Deepseek Copliot`，填写你的 `DeepSeek API Key` 并验证连接。
2. **（可选）勾选"启用联网搜索"**，让 AI 能够自动查证最新信息，无需任何额外配置。
3. 在 Zotero 文库中选中一篇论文，或直接打开 PDF。
4. 打开右侧 `Deepseek Copliot` 面板，输入问题或先输入 `/` 调出快捷命令。
5. 切到另一篇论文或 PDF 后，插件会切换到该文献自己的会话；回到原文献即可继续之前的讨论。

## 上下文与资源占用

- 一个对话绑定一篇论文或当前 PDF，不会把多篇全文混入同一个上下文窗口。
- 最近使用的 PDF 文本会在本地有限缓存，避免连续提问时反复提取；插件会控制缓存规模，避免长期占用过多内存。
- 论文内容会保持为稳定上下文，帮助服务端在连续追问时复用已有内容。
- 约 90% 的模型窗口是自动整理较早交流的软阈值，不是论文长度上限。整理不会新建或切换会话，论文全文和最近讨论会优先保留。
- 如果单篇论文已经超过所选模型的硬性上下文上限，插件会明确提示，而不会静默截断或拆分正文。

你可以这样问：

- “帮我总结这篇论文”
- “/总结 这篇论文的核心贡献”
- “/方法 解释一下作者的方法设计”
- “这篇论文的方法核心是什么？”
- “这篇论文的结论和局限有哪些？”

## 配置与使用

### 基础配置

1. 打开 `Settings -> Deepseek Copliot`
2. 填写你的 `DeepSeek API Key`，然后点击”验证连接”

### 联网搜索（v1.1.0 新增）

**无需配置 MCP 服务器，直接勾选即可使用！**

在设置中勾选”启用联网搜索”，AI 将使用 DeepSeek 官方的 Search API 自动查证最新信息：
- 搜索结果会明确标注来源链接
- 论文内容与外部资料清晰区分
- 同一个 API Key 同时支持对话和搜索

### 相关链接

- DeepSeek Platform（获取 API Key）: [platform.deepseek.com](https://platform.deepseek.com/)
- DeepSeek Search API 文档: [api-docs.deepseek.com](https://api-docs.deepseek.com/)

## 手动安装

如果你不想走插件市场，也可以从 GitHub Releases 手动安装：

1. 打开本仓库的 GitHub Releases 页面。
2. 下载最新的 `Deepseek.Copliot-<version>.xpi`。
3. 在 Zotero 中打开 `工具 -> 插件`。
4. 点击右上角齿轮菜单，选择 `Install Plugin From File...`。
5. 选中下载好的 `.xpi` 文件并完成安装。
6. 重启 Zotero。

当前稳定版本是 `v1.1.0`，手动安装文件名为 `Deepseek.Copliot-1.1.0.xpi`。
