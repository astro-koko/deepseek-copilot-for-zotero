## 本次更新

🎉 **重大更新：联网检索质量全面重构！**

Deepseek Copliot 1.2.0 针对联网查证"搜不准、搜不全、重复刷屏"三大痛点做了系统性重构，让"相关工作"类问题真正能挖出独立文献：

- **智能检索规划**：AI 先判断问题意图（相关工作 / 最新进展 / 事实核查 / 一般），再自动生成最多两条主题化查询——剥离提示词样板，相关工作附带精确标题排除，最新进展附带年份限定，不再把整段提问原样塞进搜索引擎。
- **作品级去重与主论文折叠**：同一论文在出版社、目录、索引站的多条记录按 DOI / arXiv 编号 / 标题相似度自动合并折叠，独立相关文献区不再被当前论文刷屏（实测相关工作场景从 5 条中 4 条目录页降到 0-1 条折叠）。
- **内容实体锚点检索**：从论文全文提取高频缩写与专名（巡天名、方法名等）作为第二条检索角度——施引文献通常不写原文标题，但必然讨论这些实体，突破主题词检索的盲区。
- **两段式反思检索**：首轮彻底落空时，模型自动提炼一条补充检索式再搜一次并合并结果，模拟研究者"换个关键词再搜"的真实工作流。
- **上下文注入优化**：优先使用官方"供模型消费"的检索摘要并按条封顶；结果分组标注"独立相关文献"与"当前论文自身条目"，引用边界更清晰。
- **追问不再失忆**：极短的追问（如"需要你联网搜索"）自动继承上一轮检索意图；"2026 年有相关工作吗"式年份追问自动升级为按年份检索。
- v1.1.0 的**官方原生联网搜索**（1 个 Key 通用）与**深度思考控制**（Low / Max）完整保留。

## 兼容性与安装

- 适用于 Zotero 7、8、9 和 10 全系列版本，跨 Windows / macOS / Linux 平台，统一使用 `Deepseek.Copliot-1.2.0.xpi` 安装包。
- 在本 Release 下载 XPI 文件后，在 Zotero 中打开"工具 → 插件"，点击右上角齿轮图标选择"Install Plugin From File..."，选中 XPI 并重启 Zotero。

## 快速配置

1. 打开 `设置 (Settings) -> Deepseek Copliot`，填入你的 DeepSeek API Key 并点击"验证连接"。
2. 勾选"启用联网搜索"，即可立即体验升级后的智能检索规划与文献发现能力。
