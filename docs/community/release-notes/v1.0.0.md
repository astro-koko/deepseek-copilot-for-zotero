## 本次更新

Deepseek Copliot 1.0 专注于让长篇论文阅读中的连续追问更顺滑，也让 AI 回答在 Zotero 的窄侧栏中始终清晰可读。

- **流式回复更顺滑**：减少长回答生成时的界面卡顿，状态与新内容仍会及时显示。
- **侧栏与输入框自适应**：Library 和 PDF Reader 会跟随 Zotero 侧栏实际宽度重排。长文本正常换行，代码、宽表和超长公式只在自身区域滚动，不再挤出整个对话。
- **比较内容更易读**：回答会优先采用纵向分组列表或三列以内的小表，减少窄侧栏中横向滚动宽表的情况。
- **公式显示更可靠**：普通括号英文说明不再被误识别成公式；真正的长公式仍保持完整，并可在公式区域内横向查看。
- **论文对话彼此独立**：不同 PDF 或文献各自保存会话，切回原文献即可继续原来的讨论。
- **长对话更连贯**：完整论文能放进模型窗口时会优先保留全文；只有接近窗口上限时才整理较早交流，并保留论文和最近讨论。
- **便于复用回答**：完成的 AI 回复可一键复制。

## 兼容性与安装

- 适用于 Zotero 7、8、9 和 10，使用同一个 `Deepseek.Copliot-1.0.0.xpi` 安装包。
- 在本 Release 下载 XPI 后，于 Zotero 中打开“工具 → 插件”，通过右上角齿轮菜单选择“Install Plugin From File...”，选中 XPI 并重启 Zotero。
