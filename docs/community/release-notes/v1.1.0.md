## 本次更新

🎉 **重大更新：原生集成 DeepSeek Search 联网搜索与深度思考控制！**

Deepseek Copliot 1.1.0 原生集成 DeepSeek 官方搜索能力与思考深度控制，无需额外配置即可在 Zotero 阅读论文时自动查证最新信息：

- **DeepSeek Search 原生集成**：直接接入官方 `/v1/tools/search` API，同一个 API Key 同时支持对话与联网查证，无需配置 MCP 服务器或注册第三方搜索引擎。
- **智能学术查证**：AI 根据问题自动查证前沿研究、最新复现代码与官方数据集更新，严格遵循“论文优先”基准，并在回答中明确标注外部引用来源。
- **深度思考随心控**：支持开启/关闭思考模式，新增 `Reasoning Effort` 控制（`Low` 极速扫读，`Max` 深度数理推演与实验批判）。
- **统一模型架构**：统一采用高性价比的 `deepseek-flash` 核心，旧版本配置自动无缝升级迁移。
- **原生侧栏排版自适应**：修复窄边栏宽度下的文字裁切问题，大幅提升 KaTeX 公式、表格与代码块的阅读体验。

## 兼容性与安装

- 适用于 Zotero 7、8、9 和 10 全系列版本，跨 Windows / macOS / Linux 平台，统一使用 `Deepseek.Copliot-1.1.0.xpi` 安装包。
- 在本 Release 下载 XPI 文件后，在 Zotero 中打开“工具 → 插件”，点击右上角齿轮图标选择“Install Plugin From File...”，选中 XPI 并重启 Zotero。

## 快速配置

1. 打开 `设置 (Settings) -> Deepseek Copliot`，填入你的 DeepSeek API Key 并点击“验证连接”。
2. 勾选“启用联网搜索”，即可立即体验官方联网查证功能。
