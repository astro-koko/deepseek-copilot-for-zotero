## 本次更新

`1.0.1` 修复 Zotero Library 与 PDF Reader 原生窄侧栏在完成回答后的重复收窄场景。

- 修复完成回答后侧栏继续变窄时，对话内容保留旧宽度并在右侧被裁切的问题。
- 重新约束 section body、插件挂载点和 React 根节点，让它们保持自动高度，同时跟随 Zotero 当前宽度收缩。
- 增加普通中文与英文段落、列表、公式、复制按钮和 Composer 的宿主布局回归测试。

## 测试范围

- 预发布 XPI 已通过 Zotero 原生 Plugins/Add-ons Manager 的 `Install Plugin From File...` 导入并完成冷启动复核。
- 测试重点为 Zotero 9 release；Zotero 7 至 10 的兼容范围保持不变。
- 测试不自动发送论文内容或调用 provider，而是使用已有会话验证界面布局。
